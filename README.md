TeachMe AI is an AI-powered web application that helps users learn from PDF documents in an interactive and personalized way.

FEATURES
=> Upload PDF documents
=> Choose a preferred learning style.
=> Enter a custom prompt.
=> AI-generated explanations.
=> AI-generated flashcards or quiz and many more..
=> Ask follow-up questions for deeper understanding.

TECHNOLOGIES USED
=> REACT (VITE)
=> GOOGLE GEMINI API
=> CSS
=> Java Script
